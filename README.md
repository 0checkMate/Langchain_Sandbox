# LangChain Sandbox

Learning exercises with LangChain and the Google Gemini API.

## Requirements
- Python 3.10 or later
- A free Gemini API key from Google AI Studio

## Setup
```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

## Configuration
Create a `.env` file in the project root:
```
GOOGLE_API_KEY=<your key>
```
The file is excluded from version control through `.gitignore`.

## Run
```bash
python <filename> (eg.'python 01_talking_to_gemini')
```

## Project structure
```
langchain-sandbox/
├── .venv/              Virtual environment (not committed)
├── .env                API key (not committed)
├── chroma_db/          Vector index generated by 02_rag_ingest.py
├── .gitignore          Files excluded from Git
├── README.md           This file
├── 01_talking_to_gemini     Basic Prompt -> model -> parser chain
├──02_rag_injest.py     Loads and splits document into chunks (indexing phase)
├──03_rag_query.py      Retrieval and answer generation (querying phase)
└── requirements.txt    Pinned dependencies (generated by pip freeze)
```

## Packages
| Package | Purpose |
|---|---|
| `langchain` | Core framework: prompts, chains, output parsers |
| `langchain-google-genai` | Gemini integration |
| `python-dotenv` | Loads the API key from `.env` |
| `rich` | Renders Markdown output in the terminal |

## Maintenance
After installing any new package, regenerate the dependency list:
```bash
pip freeze > requirements.txt
```

## Troubleshooting
| Symptom | Cause and action |
|---|---|
| `503 UNAVAILABLE` | Provider overloaded. Wait a few minutes and re-run. No code change needed |
| `429` | Free-tier rate limit reached. Wait, or reduce call frequency |
| `404` model not found | Model name retired. Update `MODEL_NAME` in `main.py` |
| `ModuleNotFoundError` | Environment not activated, or wrong VS Code interpreter selected |
| Output shows `[{'type': 'text', ...}]` | `StrOutputParser()` is missing from the chain |
| Embedding model 404 | Model name has been retired, Update EMBEDDING_MODEL
| Empty retrieval results | the ingest script has not been run, or the collection name differs between scripts
