# LangChain Sandbox

Learning exercises with LangChain and Gemini.

## Setup
```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

## Configuration
Create a `.env` file containing `GOOGLE_API_KEY=<your key>`.
The file is excluded from version control.

## Run
```bash
python main.py
```
